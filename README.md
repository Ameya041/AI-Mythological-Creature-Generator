# Mytho-Generator
# 🐉 AI Mythological Creature Generator

A Gradio app that generates mythological creature lore and visualizes it using AI.

## Features
- Text generation using TinyLlama
- Image generation using Stable Diffusion (sd-turbo)
- Interactive UI with Gradio
